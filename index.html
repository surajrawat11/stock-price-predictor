How It Works

The Pipeline

📥

1. Data Collection

Downloaded 4 years of real Nifty 50 OHLCV data (2021–2024) from Yahoo Finance using the yfinance library — no manual download needed.

⚙️

2. Feature Engineering

Created 9 financial features including RSI, moving averages (MA5/20/50), volatility, and volume momentum — signals real traders use.

🎯

3. Target Creation

Binary label — 1 if tomorrow's price is higher, 0 if lower. Time-series split (80/20) with no shuffle to prevent data leakage.

🤖

4. Model Training

Trained Logistic Regression (baseline) and Random Forest (200 trees). RF captured non-linear patterns and beat the 50% random baseline.

📊

5. Visualization

3 professional charts — price trends with MAs, feature importance analysis, and model comparison dashboard with confusion matrices.

💡

6. Key Insight

Daily Return was the most important feature (0.147). Nifty 50 is highly efficient — even beating 50% consistently is statistically meaningful.
